# Scarabub source sprite

Scarabub's current front sprite is the Fakemon third-place entry by **Xiros** from the
Whack a Hack! **Concurso de Sprites SP 2026**. The contest results describe it as a
small bug Pokémon resembling Heracross.

Source page:
https://www.whackahack.com/noticia/concurso-de-sprites-sp-2026-resultados-y-entrega-de-premios/

The checked-in `scarabub_xiros_source.png` is the original pixel artwork isolated
from the published award image without redrawing or resampling. The PJR conversion
keeps the 39x44 artwork at native pixel size and only performs the permitted GBA
palette/indexing and 64x64 canvas placement conversion.

Creator credit: Xiros / Whack a Hack! Concurso de Sprites SP 2026.
