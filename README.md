# RelicDex — Pokémon Relics Ultimate

444-entry mobile Pokédex with all 444 Pokémon sprites embedded directly in index.html (including Paldean Wooper, Seviian Noibat & Noivern, Clodsire and PRL Annihilape).

## Publish

GitHub repository Settings → Pages → Build and deployment → Deploy from a branch → branch **relicdex-pages**, folder **/(root)** → Save.

Expected URL after Pages activation: https://jamesthoward2112-tech.github.io/Pokemon-Johto-Relics/

This branch intentionally contains only the standalone static website, separate from the PRU ROM source branch.
